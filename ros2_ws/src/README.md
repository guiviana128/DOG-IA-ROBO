# ROS 2 Workspace - DOG-IA

Este diretório contém os pacotes-fonte (`src/`) do ecossistema ROS 2 do projeto:

- `dog_ia_description`: Modelos URDF/Xacro, malhas 3D e mundos Gazebo.
- `dog_ia_bringup`: Launch files para inicialização integrada de nós e simuladores.
- `dog_ia_perception`: Filtragem do sensor LiDAR 360° e detecção de semáforos por visão computacional.
- `dog_ia_navigation`: Parâmetros do Nav2, costmaps com margem para o usuário e máquina de estados finitos (FSM).
- `dog_ia_teleop`: Controle e comandos de interface háptica na guia.
